Questions & Answers

Frequently Asked Questions

Does Wajji TinyHand PRO require installation?

No! It is distributed as a single standalone executable (WajjiTinyHandPRO.exe). You can run it directly from your Downloads folder, Desktop, or a USB thumb drive without administrator permissions.

Does it work with Zoom, Microsoft Teams, and Loom?

Yes. Because the pointer and drawings are rendered on a hardware-accelerated Win32 borderless layered desktop window, any screen sharing software captures your hand and annotations in real time.

Can I add my own custom pointers and sounds?

Yes! The settings window includes a Custom Pointer uploader for transparent PNGs and an audio uploader supporting any WAV or MP3 click sound.

How is this inspired by macOS TinyHand?

We love the design philosophy of Kamran Ahmed's macOS app (nilbuild/tinyhand). We wanted Windows users to enjoy the same premium presentation experience, so we architected a native Windows engine with full attribution under the MIT license.
